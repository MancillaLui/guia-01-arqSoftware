## Descripción del Curso
El curso de Arquitectura de Software aborda las decisiones de alto nivel necesarias para estructurar, diseñar y construir sistemas de software escalables, mantenibles y eficientes. Comprende el estudio de patrones arquitectónicos, diseño en capas, modularidad e integración de entornos modernos de desarrollo.

---

## Expectativas del Estudiante
* Comprender y aplicar buenas prácticas en la toma de decisiones arquitectónicas en proyectos reales.
* Dominar la integración de herramientas de control de versiones y entornos backend como Node.js y Express.
* Adquirir capacidades para diseñar e implementar arquitecturas modernas, limpias y escalables.
